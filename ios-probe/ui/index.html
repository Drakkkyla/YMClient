YMProbe

Проверка фонового звука для iOS-версии YMClient. Играют 30-секундные превью подряд.

  1. Нажми один из режимов — музыка заиграет.
  2. Заблокируй экран на 2–3 минуты (должно смениться 4–6 треков).
  3. Проверь кнопки на экране блокировки.
  4. Разблокируй, нажми «Скопировать журнал» и пришли его.
—
Ничего не играет
